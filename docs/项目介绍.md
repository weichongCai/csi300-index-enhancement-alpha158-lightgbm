# 项目介绍

本项目研究基于量价特征的沪深300指数增强方法，将数据处理、相对收益预测、组合构建、执行模拟及研究诊断组织为可复算流程。核心模型使用Microsoft Qlib的Alpha158特征和LightGBM，保留固定预测、逐日账户、订单、研究统计与输入指纹。

## 研究目标

在股票多头框架下，通过横截面选股获得相对沪深300全收益指数的超额收益，同时评价主动风险、回撤和交易成本。指标分别报告平均年度超额IR、全期超额IR、复合年化收益及绝对/相对回撤。

2016—2025为策略开发区间。每边3bp成交价滑点场景的平均年度超额IR为1.378，全期IR为1.344，年化收益16.66%，最大绝对回撤−29.47%。完整对照和图表见[首页](../README.md)。

## 系统流程

```text
历史成员区间与复权行情
        ↓
Alpha158量价特征 / 五日beta残差收益标签
        ↓
按时间切分训练、验证，按标签成熟日隔离边界
        ↓
冻结LightGBM预测 / 固定Ridge参考
        ↓
前收盘计划 → 次日模拟收盘成交 → 连续现金与持仓账户
        ↓
超额收益评价 / 因子统计 / 风险与执行诊断 / 基金对照
```

## 研究模块

| 模块 | 实现内容 | 输出 |
| --- | --- | --- |
| 数据处理 | 历史沪深300成员、复权尺度、量额单位、缺失与可交易性处理 | 行情格式说明、源数据指纹 |
| 特征与标签 | 158项公开量价表达式、截至信号日的beta、成熟五日残差目标 | 特征字典、标签交叉核对 |
| 模型 | 两个冻结LightGBM应用时间段、同样本同标签的固定Ridge | 模型文件、训练记录、固定预测 |
| 组合执行 | 约50只持仓、每日通常最多替换5只、整手、现金及交易限制 | 逐日账户、订单与持仓 |
| 成本模拟 | 买卖基础费用、最低费用、每边3bp不利成交价、价格区间和日容量检查 | 独立滑点账户与执行核查 |
| 因子评价 | IC、RankIC、非年化ICIR、覆盖率、逐年和五组前瞻均值 | 逐日统计、分组与滚动曲线 |
| 冗余与不确定性 | 月末横截面相关矩阵、连续块Bootstrap、158项BY校正 | 相关对、置信区间、校正统计 |
| 风险与容量 | 前日持仓风险代理、集中度、换手、静态规模压力及条件状态分析 | 风险暴露、执行和容量表 |
| 外部对照 | 五只沪深300增强基金、统一全收益基准及投入时点 | 收益、IR、跟踪误差和净值比较 |

## 研究结论

固定Ridge在同交易规则和3bp滑点下的平均年度超额IR为0.429，低于LightGBM的1.378；LightGBM平均RankIC约0.0583，Ridge约0.0514。该结果比较两条完整建模流程，不单独识别全部非线性收益来源。

特征诊断发现部分方向占比表达式排序高度重复；单因子的经济直觉与统计结果也不总是一致。158项检验经BY校正后32项拒绝平均RankIC为零，但统计关联不等于独立可盈利策略。连续块抽样用于表达不确定性，不能消除开发期反复研究造成的选择偏差。

执行诊断显示年均双边换手约44.86倍，成本与容量具有实际影响。现有风险代理覆盖beta、波动、动量和流动性；完整历史行业、市值、基本面与基准权重尚未齐备，因此当前版本没有完整Barra主动风险归因或行业风格中性优化。

## 验证与复现

模型预测索引、信号与成交时序、费用、滑点、日现金及日容量保留核查记录；原存储残差标签抽样800条与独立实现交叉核对，最大绝对误差小于3×10⁻¹⁷。发布版记录17项测试通过，下载后研究表格与五张图复算一致。

仓库可直接从保存统计重算研究报告；重新生成成交需要Qlib原始行情；重新构造特征统计和训练还需相应本地缓存。完整命令见[首页复现说明](../README.md#复现与验证)，研究原理见[研究流程与证据](研究流程与证据.md)，数据与输出范围见[研究诊断明细](../results/research/README.md)。
