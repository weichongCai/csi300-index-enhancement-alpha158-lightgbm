# 组合优化与主动风险管理

本项目把研究分成三个职责：Alpha模型决定倾向持有什么，组合层决定各持有多少，执行层决定哪些订单能够成交。新增模块是独立研究实验，原LightGBM、预测及发布账户保持冻结；新实验结果、失败记录和限制均单独保存，不自动替换模拟盘。

先前的分层风险预算候选未通过整体检验，结果保留用于解释模型风险。后续改进保持原日频选股机制，以过去已成熟的五日开盘收益校准分数，再过滤无法覆盖交易成本的普通换股；开发回测中平均年度超额IR由1.550提高至1.579，CAGR由17.69%提高至17.82%，最大相对回撤由-10.13%减轻至-8.96%。

**当前保留的改善候选是边际净效用门槛。** [改善实验](../results/net_edge_improvement/README.md)完整说明校准、成熟时点、成本、五组消融及不确定性。下面的完整权重风险预算系统是先前研究方法和失败证据，不是改善候选正在使用的全部规则。

### 当前候选怎样落到组合优化

LightGBM训练目标仍为原五日收盘市场残差收益。新增一维执行校准的标签为t+1至t+6开盘股票收益、去除信号日横截面均值，两者用途不同。校准对每天的分数采用相同的历史成员横截面标准化，再根据退出开盘已经发生的样本计算斜率。最近126个有效斜率按60日半衰期加权，至少60个成熟信号日；此前精确使用原规则。

对原Top50/Drop5提出的换股，计算“非负历史均值斜率×新旧z分数差”，再扣除卖出15bp、买入5bp、两边3bp滑点、最低费用及主动风险扣减，普通换股仅在净效用为正时执行。风险扣减为风险厌恶4/2×5日×日主动方差变化/被替换持仓权重，市场beta直接由过去收益估计，不对基准施加单位阵收缩。已有空缺补齐、股票池退出及必要持仓数量处置单独记录。这是原候选交易集合上的局部净效用选择，没有声称全市场最优。

最终候选不启用额外的一倍标准误折减，启用风险厌恶4的五日主动方差扣减。在同时达到基线收益和两类IR门槛的版本中，选择最大相对回撤最小的一组；收益提升更多的无风险扣减版本也披露。四个变体和此前实验均参与开发期选择，不能包装成新样本外结论；模拟盘没有自动切换。


## 研究问题：如何减少跑输指数时的损失

指数增强的核心风险是相对基准的偏离。设账户净值为P，基准净值为B，相对净值V=P/B，相对回撤为V/历史最高V−1。账户上涨也可能发生相对回撤。主动日收益定义为rP−rB，超额IR定义为主动日收益均值除以标准差再乘√252。日主动收益直接连乘不等于P/B。

原开盘账户2025-05-30至2025-09-03上涨6.13%，基准上涨18.09%，相对回撤10.13%。[持仓和交易精确链接的详细归因](../results/deep_attribution/README.md)提供了以下线索：

| 事后归因分量 | 相对损益贡献 | 对风控的启示 |
| --- | ---: | --- |
| 市场敏感度偏离 | −2.90个百分点 | 不能只防beta过高，也要防牛市中beta过低 |
| 价格指数/全收益基准差 | −1.64个百分点 | 风险估计与评价尽量统一全收益基准 |
| 波动风格 | −2.41个百分点 | 低波动偏离同样会形成主动风险 |
| 已覆盖股票残余 | −1.62个百分点 | 总跟踪误差应包含股票共同波动之外的风险 |
| 买入、卖出当日日内增量合计 | −1.04个百分点 | 交易本身需要独立检查；此数不能证明长期不换股更好 |
| 基础费用和滑点 | −1.60个百分点 | 需要在组合优化目标中显式考虑成本 |

还有共同项、其他风格等正负分量，完整表合计−10.13%。这些是依赖代理模型的解释，不是因果证明，也不是互不相关的独立风险。2022年的最大绝对回撤主要来自市场下跌，不能据此要求满仓指数增强同时消除市场风险。

## 方法来源和取舍

Boyd等的[Multi-Period Trading via Convex Optimization](https://web.stanford.edu/~boyd/papers/cvx_portfolio.html)给出了预测、风险、交易成本和约束的统一决策框架。本项目借鉴其**单期**优化思想，没有实现多期预测控制，也没有声称完整复现论文实证。

Ledoit与Wolf的[协方差收缩研究](https://ledoit.net/honey_abstract.htm)指出，样本协方差的估计噪声会干扰组合优化。本项目完整历史子集采用[scikit-learn LedoitWolf](https://scikit-learn.org/stable/modules/generated/sklearn.covariance.LedoitWolf.html)的缩放单位阵目标，不是该篇论文常相关目标的逐项复现。部分历史持仓使用单市场条件模型扩展，并明确承认遗漏行业和残余相关性。

这些来源提供建模依据；10%风险预算、权重上限等是本研究的治理选择，不是论文保证的最优参数。开发区间已反复使用，不能把此次检验称为独立样本外验证。

## 一、风险模型：不虚构历史指数权重

没有完整、经核实的历史沪深300权重和十风格基本面数据，不能做完整Barra持仓主动暴露归因。但估计账户与基准收益差的波动，并不必须先得到指数逐股权重。

构造联合随机向量R=(r1,…,rn,rB)，协方差为Σ，组合股票权重为w，剩余现金收益近似为零。定义v=(w,−1)，则：

```text
主动收益 = Σ_i w_i × r_i − rB
预测年化TE = √[252 × v' Σ v]
           = √[252 × (w'Σss w − 2w'ΣsB + ΣBB)]
```

基准系数始终是−1，即使股票仓位只有99%。不能用“股票超额收益的协方差”忽略现金相对基准的偏离。股票复权收益与全收益基准仍有数据构造差异，不等于已证明原始现金股份账簿一致。

每次决策只读取信号日及此前最多252个交易日。当前数据合格的历史成分股进入候选池；新入选须有完整252日收益。风险估计分三类：

1. 完整历史股票与全收益基准联合估计收缩协方差。
2. 部分历史旧持仓至少有126对股票/基准收益，估计ri=βi rB+εi。其残余与完整子集残余、其他部分历史股票残余独立，是模型假设，不是把缺失收益填成零。该条件扩展保留协方差半正定。
3. 不足126对的旧持仓标记为无法估计，采用beta=1、100%年化特质波动作为**风险准备情景**；这些持仓的特质准备按完全相关聚合，避免凭空分散。它不是经验估计，也不是损失上界。优化目标持仓上限设为零；若停牌等原因不能卖出，实际持仓和准备继续保留。

历史数据短缺必须进入监控表，不能通过删除实际持仓来让风险看起来更低。VaR/ES若没有足够共同有效历史则留空，不冒充有可靠估计。

## 二、组合优化：保护Alpha偏好，约束主动风险

原LightGBM输出是排序分数，未经校准，不能直接当作预期收益率。此次将合格股票中得分最高50只各1.98%的组合定义为参考权重q。优化器在更广的合格成分股及实际旧持仓中选择w，用偏离q的代价保留原信号偏好。

```text
最小化：0.5 ||w−q||²
        + 0.1 × 预测年化主动方差
        + 0.0008 Σ买入权重 + 0.0018 Σ卖出权重
        + 10 × 主动方差预算超出量s

其中：s ≥ 0，预测年化主动方差 ≤ 0.10² + s
```

该目标是“参考组合跟踪＋风险＋成本”，不是经过预期Alpha校准的经典均值方差最大化。四项系数共同定义研究偏好；成本只近似一次换仓的线性损耗，不代表全部市场冲击。这里也没有把年度收益、单次费用混在一起宣称经济最优。

硬约束：w≥0，股票目标权重之和99%，单股目标上限4%，目标beta在0.85—1.15之间，每次双边权重变动之和不超过40%（初始建仓例外）。不合格的旧持仓可减持而不可加仓，无法估计的旧持仓目标为零。beta已含99%股票仓位，剩余现金beta视为零。

进一步增加**排序信号预算**：将当时合格股票的预测分数转为百分位排名，先单独求解在仓位、单股上限、beta、换手等硬约束下能达到的最大排序暴露Smax。如果同日Top50参考的排序暴露可达到，则要求保留参考水平；若不可达到，则以Smax减去极小数值容差作为要求，同时显式记录参考缺口。这样按优先级处理约束冲突，避免高参考分数长期阻塞调仓。

该预算限制优化器用大量低分股票换取较小的TE；它保留的是模型偏好，不是保证相同真实收益。第一阶段是在硬约束下求信号可行前沿，第二阶段在达到预算的组合中权衡风险、偏离参考和成本。没有利用未来收益决定Smax，也没有把排序值称为预期收益率。

**10%是软风险预算。** 2015年高波动历史下，99%股票等约束的组合未必能满足10%TE。若将其硬卡而不允许任何可行性处理，优化器可能从初始现金状态一直无法建仓。系统保留投资要求，显式惩罚并记录超预算量，禁止把空仓躲过下跌解释成模型改进。其他硬约束无解或求解精度不合格则不发布新目标，保留失败原因。

使用CVXPY与CLARABEL求解，再独立检查输出权重、beta、换手、信号预算和TE预算超出量。目标函数整体乘1000改善数值尺度，不改变同一可行域下的数学最优解；它不是提高收益的参数。微小目标低于1bp时，订单编译为全额退出或不新买，避免数值尾仓长期遗留；理论目标和实际成交后持仓分别记录。

## 三、执行：目标可行不等于订单可成交

每个ISO周首个交易日调仓，信号来自前一交易日收盘。上一收盘价将权重转换成固定数量订单，次日开盘按原实验规则成交；每边3bp不利价格，买入5bp、卖出15bp费用及最低5元；按前20日已完成量额5%限制成交。

开盘跳空、整手、现金不足、容量、停牌和方向限制会使实际持仓偏离目标。目标4%上限不等于每个收盘实际权重都小于4%。回测继承先卖后买、卖出资金可在同次执行再用的研究假设，尚未重放集合竞价冻结资金和排队；不将其写成生产系统已解决的能力。

## 四、事后监控与风险处置

收盘后用实际持仓及截至当天的数据生成下一日风险快照：预测TE、beta、最大权重、有效持股数、风险数据覆盖、历史VaR95/ES95、过去最差单日情景、相对净值回撤。

| 检查 | 阈值或定义 | 处置 |
| --- | --- | --- |
| 预测TE | 超过10%软预算 | 显式报警；下次计划优化继续惩罚超出量 |
| 组合beta | 小于0.85或大于1.15 | 区分目标、成交偏差与价格漂移；下次计划优化纠偏 |
| 单股漂移 | 实际权重大于4.5% | 报警并检查容量、未成交及价格上涨 |
| 相对回撤 | 小于−6%预警、小于−8%升级 | 复核风险、选股、风格和交易来源；不自动减成现金 |
| 无法估计风险 | 实际持仓有准备项 | 限制新增、尝试退出，保留未成交记录和准备 |
| 求解无解/精度不足 | 状态非optimal | 不发送新目标、不隐式放宽硬约束 |

回撤报警不是回测择时开关；这些阈值没有根据未来回撤改变交易。当前版本是**离线研究风控系统**：自动按周优化，逐日生成报警和复核表；未接入实时行情、券商、通知推送或自动日内应急执行。

额外压力测试包括市场一次上涨/下跌10%时的线性主动损益近似(β−1)×市场冲击，以及所有波动放大1.5倍的TE情景。这些不是预测，也没有模拟相关性突变、流动性枯竭和价格跌停连锁反应。

## 五、风险预测怎样接受检验

逐日比较收盘持仓的事前风险和下一日**固定该持仓、不调仓、不计费用**的假想主动收益，计算标准化收益及历史VaR95突破率。它检验库存风险模型，不是新策略可交易收益。实际换仓账户另报扣费后60日滚动TE。只有数据可用的日期才统计，留空日期和准备项不能被隐去。

预测TE是未来波动的估计，不保证未来最大回撤。VaR95突破率接近5%也不代表极端损失已被控制；ES来自历史尾部，样本很少且不一定包含将来风险。部分历史股票的残余独立假设可能低估行业共振，准备参数也不是经统计校准的风险上限。

主动风险Euler分解采用年度方差贡献cj=252×vj×(Σv)j，满足Σcj=TE²；除以TE得到波动贡献，合计TE。基准为联合向量中的负权重项，因此单项贡献允许为负，不能把它当作只含股票、全为正的风险饼图；也不能将这种证券/基准分解称为完整Barra行业风格归因。

## 六、如何评价实验是否值得采用

对照有三组：原日频Top50/Drop5账户；同数据准入的周频Top50等权账户；周频风险/成本优化账户。后两者用于辨认组合构建作用；与原账户的比较同时含有频率、候选准入等变化。优化组合允许用Top50之外股票降低风险，不能把效果全部归因于权重微调。

优先看最大相对回撤、全期和逐年超额IR、TE、扣费收益、股票敞口和换手。再看2016—2020与2021—2025两个开发子区间，以及2022和2025旧回撤窗口。只改善旧窗口但恶化其他时段，不能算稳定改善。报告对IR差值使用20日配对块Bootstrap，区间只表示描述性抽样不确定性，不能校正整个项目此前所有尝试。

数据可用性与求解可行性检查中被否决的版本保留为本地研究记录，不作为可用策略发布。不得因为有优化器就自动采用新版；若收益或超额回撤变差，应保留原策略并定位风险模型、成本偏好和信号损失，不能挑最好的图替换结论。

此次排序预算是在观察风险优先原型的信号损失后加入的，因此最终设计已经利用开发期反馈；风险优化原型的失败是研究证据的一部分。没有做参数网格搜索，不等于没有策略选择偏差。报告不能把后续同区间重跑包装成全新样本外表现。

## 岗位讨论时应能说清楚的判断

- 为什么不用分数直接优化收益？排序分数没有收益单位，需要训练期/历史滚动校准；此次通过参考权重保留信号，而不伪装预期收益。
- 为什么控双向beta？超额回撤既可能来自下跌中过高暴露，也可能来自上涨中过低暴露。
- 没有指数权重能否做指数增强优化？能估计收益空间TE；不能因此声称行业主动权重中性或完整Barra归因。
- 为什么用收缩？降低协方差估计噪声和极端权重敏感度；它不会保证降低真实回撤。
- 优化器无解怎么办？先区分硬约束和软预算，不静默放宽；记录失败、保留真实持仓与风险，不能把“没建仓”包装成风控收益。
- 风控为什么不能只看最大回撤？它是路径相关的事后统计，需要结合可预见风险、成交约束和参数稳定性。
- 如何验证没有未来信息？按信号日截断所有风险输入、验证标签成熟时间、使用前一日量额，并用未来数据扰动测试确认历史风险和权重不变。
- 系统还缺什么？可靠历史权重和行业/基本面风险模型、风险准备校准、实盘资金冻结与冲击、持续独立样本验证及实时应急流程。
