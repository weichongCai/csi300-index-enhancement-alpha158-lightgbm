# 基金对照数据

`published_nav.csv`包含五只基金2015-12-31至2025-12-31的全部12195条公布记录，每只2439条；列为基金代码、日期、单位净值、每份现金分红。代码保留前导0。来源是2026-10-26保存的公开历史净值，不是本次重新挑选的收益更差样本。

先在全部公布日期按`(当日单位净值+每份分红)/前一公布日单位净值`重建分红再投资财富，再对齐模型2430个交易日。每只基金另有8个非共同交易日的公布日期，不在生成总回报前丢弃。没有将累计净值当复权净值；缺失共同日期或重复公布日期会报错。

模型、基金和H00300全收益指数均按2016首个建仓日收盘投入；基金首日收益设0，模型首日交易费用保留。基金净值已包含基金层面的运营费用，模型仅扣已声明交易费用；基金初始申购费及赎回费未另行模拟。
